# QAgent Catalog SQL Reference

These SQL files are **engineering references**, not the public Console contract.

Use them for:

- deploy validation;
- production diagnosis;
- backfill/recovery checks;
- architecture audits;
- remembering how each Foundation milestone was verified.

The future Console must consume the tenant-aware Catalog Query API (Foundation 07.5.11), not execute these SQL statements directly.

`foundation-07.5-validation.sql` consolidates the most useful queries from 07.5.2 through the current Foundation.
